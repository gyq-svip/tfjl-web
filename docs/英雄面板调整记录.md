## 一、怎么修（速查）

| 现象 | 修哪里 |
|---|---|
| 某英雄整体偏大/偏小 | 改 `data/hero-spine/index.json` 里该骨骼文件夹的 `scale`（>1 放大，<1 缩小）；改完推 GitHub 即热更 |
| 角色左右偏移 | 同上配置 `offsetX`（画布比例，正右负左） |
| 身体不显示、只剩一团特效 | 模型插槽 setup 附件名为空（附件只在皮肤里）→ `spine-hero.js` 附件名回填已自动处理 |

| 融合列表为空/不能切换 | 名单只认 `skins/fusions.json`（管理面板维护，30 组官方融合）；单卡「选副卡」行在 `app-core.js` 的 `paintFusePickRow` |
