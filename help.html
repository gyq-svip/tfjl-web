🎮 塔防精灵助手 · 新手帮助

一句话：这是一个帮你管理塔防精灵「阵容脚本」的工具，网页就能用，桌面版还能把脚本存到你电脑里。

🚀 快速开始（5 步）

  1. 打开网站 / 桌面版，输入密码进入主界面。
  2. 选 10 张卡组成手牌：点卡牌加到「我的手牌」，右键可收藏常用卡。
  3. 拖卡到战斗槽摆好站位，点右上角 💾 保存为一个「项目」。
  4. 想用别人的脚本？点右上角 📢 需求墙，看到喜欢的脚本点「导入」即可。
  5. 想存到本地？桌面版在 📁 里先配置「老马目录」，脚本就能「导入到老马」存进电脑。

📚 功能详解

📁 项目管理

把阵容按项目分类保存，方便日后查找。每个项目可包含：脚本文件、参考图片、阵容站位、皮肤融合，还有记事本记录战车与注意事项——保存后都跟着这个项目走。

📄 脚本文件（核心）

点工具栏的 📄 打开面板：

• 扫描：自动扫描出你电脑/目录里的脚本，按 寒冰 / 暗月 / 漩涡 / 合作 / 深海 / 活动 / 其他 7 类分好。

• 搜索：选某分类后输入关键字模糊匹配，不同类用不同颜色标识。

• 解析到手牌：脚本一键变成可拖拽的站位，调整一目了然。

• 分享到需求墙：所有人都能看、能下载、能直接导入。

💡 桌面版还有「导入到老马」：把选中的脚本存进你本地配置好的目录（需先在 📁 设置里配好目录）。

📢 需求墙

发布需求、分享脚本、互动交流的地方。可上传脚本文件（最大 10MB），消息默认永久保存（也可设限时），窗口还能拖动。

🏪 拍卖行

闲置物品自由上架、交换、求购，入口在右上角 🏪。完全免费，纯玩！

🔍 脚本解析与生成

支持把文本解析成手牌，自动生成活动 / 副本脚本（带时间轴）。已支持蛇女、雷精灵、天使、火炮、虎弓、后羿等阵容，遇到新阵容会持续完善。建议生成后手动微调，效果更佳。

🌐 在线版 / 离线版

在线版：浏览器直接访问，支持访问统计，网络异常可切离线版。

离线版：完全离线可用，数据存在本地，无需网络。

点 🌐 按钮可快速切换；☰ 菜单里可下载离线版 / 桌面版。

💾 备份恢复 & ⭐ 收藏

☰ 菜单里可全部备份 / 恢复，或只备份单个项目，方便换设备或分享。

右键卡牌可加到常用收藏，下次直接拖用。

❓ 新手常见问题

「导入到老马」为什么弹出的是设置界面？

说明你还没在 📁 APP本地设置 里配置「老马目录」。先打开 📁 选好合作脚本 / 活动 等目录并保存，之后再点「导入到老马」就会让你选存到哪个目录了。此功能仅桌面版 App 可用。

数据存在哪里？会丢吗？

在线版数据存在你浏览器的本地缓存；离线版 / 桌面版存在本机。建议定期用 ☰ 菜单的「全部备份」导出一份 json 留底。

扫描要等多久？

取决于目录里文件多少，一般几秒。扫描按文件名关键字自动归类到 7 个分类。

生成的副本脚本不准怎么办？

自动生成是参考，建议生成后手动微调站位和时间轴，效果更贴合实战。

怎么看别人分享的脚本？

点右上角 📢 需求墙，找到脚本点「导入」即可直接用到你的手牌里。
