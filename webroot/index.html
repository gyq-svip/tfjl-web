📖 功能使用说明

🏠 房间管理

白名单模式：

  • 白名单为空时，所有房间都可以进入（开放模式）
  • 白名单不为空时，只有列表中的房间可以进入（限制模式）

添加房间：

  • 输入房间ID（如：TF001）
  • 可选填房主昵称，房主可管理该房间

删除房间：

  • 删除时会同时删除房间所有数据（拍品、消息、图片）
  • 此操作不可恢复，请谨慎

房主功能：

  • 房主由管理员指定，只能管理自己房间的商品
  • 房主可以查看房间统计、下架商品
  • 房主入口：拍卖行面板右上角"👑 房主"按钮

🏪 商品管理

管理员：可查看所有房间商品，可下架任意商品

房主：只能查看和管理自己房间的商品

下架操作：输入房间ID后点击"加载商品"，选择要下架的商品

商品ID格式：时间戳后6位+随机3位（如：123456_a1b）

📊 拍卖统计

查看统计：输入房间ID后点击"加载统计"

统计内容：

  • 卖家排行榜（按成交金额排序）
  • 买家排行榜（按成交金额排序）
  • 拍卖记录详情
  • 正在拍卖的拍品（显示卖家、当前买家、剩余时间）

数据备份：可导出JSON格式备份文件

👤 昵称管理

昵称唯一性：

  • 昵称全局唯一，不能重复使用
  • 昵称存储在索引文件的 usedNicks 列表中
  • 清除缓存后，之前的昵称无法使用

重置昵称：

  • 管理员可在"昵称管理"中重置用户昵称
  • 重置后该昵称从 usedNicks 列表中移除
  • 用户可以重新使用该昵称

⚙️ 系统设置

索引文件ID：

  • 固定值：a32a0628bd9275f3a4922cd12cf298c9
  • 所有设备必须使用同一个索引文件ID
  • 如果误删，需要修改代码中的 GIST_ID 常量

GitHub Token：

  • 需要创建 GitHub Personal Access Token
  • 权限需要勾选 gist
  • Token 格式：ghp_xxxxxxxxxxxx

🧹 清除缓存

何时需要清除：

  • 出现 403 Forbidden 错误
  • 每次刷新重复创建配置文件
  • 旧的 Gist ID 缓存导致 404 错误

清除后：刷新页面，系统会自动重新获取数据

⚠️ 注意：清除缓存后，之前的昵称无法使用，需要管理员重置

🗑️ 配置文件管理

功能：批量删除多余的 Gist 配置文件

操作：

  • 全选/反选：快速选择文件
  • 删除选中：删除勾选的文件
  • 删除空配置：删除没有内容的文件

⚠️ 注意：索引文件不要删除！

🔨 拍卖行使用

进入房间：

  • 输入房间ID（默认 TF001）
  • 输入昵称（只能设置一次）

发布拍品：

  • 选择品质、职业、起拍价等
  • 可上传图片（限制2MB）
  • 拍品ID自动生成（时间戳后6位+随机3位）
  • 图片存储在独立Gist，文件名包含时间戳和随机数

出价：

  • 点击 +10/+20/+50 快速出价
  • 或输入自定义出价（需大于50）
  • 出价有10秒冷却期，防止并发冲突
  • 出价成功后显示当前最高价

刷新：点击刷新按钮获取最新数据

房主管理：点击"👑 房主"按钮管理房间

💬 消息管理

发送者：

  • 2分钟内可撤回（显示"撤回"按钮）
  • 超过2分钟可删除（显示"删除"按钮）
  • 只能撤回/删除自己发的消息

管理员/房主：

  • 点击聊天框旁的"🛡️ 管理"按钮进入管理模式
  • 管理模式下可删除任何人的消息
  • 管理员（gyq）可管理所有房间
  • 房主只能管理自己房间

自动清理：

  • 超过7天的非系统消息自动清理
  • 系统消息（拍卖发布提示等）不受影响

🔒 安全机制

出价锁机制：

  • 出价时设置10秒锁，其他人无法同时出价
  • 出价完成后自动释放锁

昵称唯一性：

  • 昵称全局唯一，防止重复
  • 清除缓存后需要管理员重置

图片唯一性：

  • 图片文件名包含时间戳和随机数
  • 避免多人同时发布时文件名冲突

🃏 卡牌数据管理（管理员）

① 添加融合卡：

  • 管理员面板 → 🃏 卡组管理 →「➕ 添加融合卡」
  • 填融合卡名（必须正好=2张基础卡，如 小野酋长 / 影魇）+ 选职业/品质 → 校验 → 确认写入 fusions.json
  • 点「🚀 一键推送 fusions.json」到 GitHub（自动部署）；或手动 git push
  • 下方「已添加的融合卡」列表可查看 / 🗑 删除

② 添加新基础卡（新英雄）：

  • 卡组管理 →「🆕 添加新英雄」页签 → 填英雄名 + 选职业 + 选品质(金/紫) → 可填「卡牌描述」「魔化描述」(均可选，悬停卡牌可见) → 确认写入 cards.json
  • 写入后自动推送到 GitHub / Gitee，刷新后所有端立即可见（无需手动 git push）
  • 用户 App 重启 + 硬刷新，新英雄自动出现在对应金/紫卡类职业子分类
